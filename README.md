# Buscador de Livros Online

Este projeto é uma aplicação web que permite buscar livros disponíveis online, utilizando a API do Open Library. É possível encontrar livros de diversos gêneros, autores e períodos, incluindo obras de domínio público e livros protegidos por direitos autorais.

## Funcionalidades

- Busca de livros por título ou autor.
- Exibição de informações como título, autor, ano de publicação e capa (quando disponível).
- Interface simples e responsiva.

## Como usar

1. Digite o nome de um livro ou autor na barra de busca.
2. Clique em "Buscar".
3. Veja os resultados listados com detalhes dos livros encontrados.

## Tecnologias

- React 19
- TypeScript
- Vite
- Axios

## Instalação e execução

```bash
npm install
npm run dev
```

Acesse `http://localhost:5173` no navegador para utilizar o buscador.

## Fonte dos dados

Os dados dos livros são obtidos da [Open Library API](https://openlibrary.org/developers/api).
